# Data-Centric-Programming-Assignment

## Description
The dataset records Monster drink purchases. Each record includes a unique Monster ID, the date and time of purchase, the Monster type, and the price. The dataset contains two records.

## Data Dictionary
| Feature Name | Data Type | Description |
|---|---|---|
| MonsterID | integer | Unique identification number for each record |
| Date | date | Date the purchase occurred |
| Time | time | Time the purchase occurred |
| MonsterType | string | Type of Monster drink purchased |
| Price | float | Recorded price of the drink; the currency is not specified |

## Questions
Questions to be answered after analysing the data:
1. What is the average price of a Monster drink?
2. Which Monster type was purchased most often?
